## 一、 中间明细"灵活显示"核心能力设计

商务工程师在算量工作台（MODULE 4）中，对构件明细的查看和操作需求具有极强的多场景特性。必须支持以下 4 大"灵活显示"能力：

### 1. 多维度视图一键切换 (View Mode Toggles)
* **视图 A【构件平铺工作表 (Flat Grid)】**：类似 Excel 的纯二维数据表，适合批量录入、快速核对构件编号、规格、材质、件数、吨位；
* **视图 B【WBS 空间层级树状展开 (Hierarchical Tree Grid)】**：按标段/区域（A区、B区、C区）→ 结构系统（钢柱、钢梁、网架、天窗）逐级分组折叠与汇总（显示小计吨位与件数）；
* **视图 C【三阶段成本穿透透视 (3-Phase Cost Penetration)】**：行内直接内嵌展开构件的【制作成本明细】（主材、损耗、制作基价、厚度加价、预拼装）、【运杂费】、【安装成本明细】（拼装、吊装、机械、面漆），让每一个单价透明可查；
* **视图 D【甲方商务清单对照 (BQ Alignment)】**：显示构件归属于甲方哪一项清单（如 010101 实腹钢柱），并对比自算量与甲方清单量差率。

### 2. 动态列显隐与列定制 (Flexible Column Picker)
提供勾选框控制列展示，适应不同审查场景：
- `基础工程量列`：构件编号、名称、截面规格、材质、件数、单件重、总重；
- `几何与工艺推导列`：截面分类、最大板厚、表面展开比 (m²/t)、板厚调价档位；
- `定额拉取信息列`：匹配制作定额 ID、安装定额 ID、材料快照出厂除税价；
- `综合单价与合价列`：两票制综合单价 $C_J$、EXW 单价、合价总额。

### 3. 多条件快速筛选与高亮告警 (Filtering & Highlighting)
* **截面族筛选**：十字柱、箱型柱、H型钢、圆管、焊接球网架、空间桁架；
* **材质规格筛选**：Q355B、Q235B、Q345GJC、Q420B；
* **特征告警染色**：
  - 特厚板染色（板厚 $\ge 80\text{mm}$ 标橙，提示超厚板加工加价风险）；
  - 自动拉取异常未匹配染色（若出现特异规格定额库无对应条目，标红提示人工覆写）。

### 4. 双模交互：行内光标编辑 + 弹窗精细录入
* 支持直接在表格内双击修改数量、规格，修改后系统在 $0.05\text{s}$ 内**自动重算并重新拉取定额**；
* 支持点击工具栏弹出 `TakeoffDialog` 进行带向导的精细录入。

首轮执行闭环涵盖从原始 Excel 数据提取到最终两票制结算与倒轧平衡的全链条：

```

       │ 提取湛江北站实腹钢柱、箱型钢柱、圆管柱、网架主管等实际算量数据

       ▼
[中间明细灵活工作台渲染]
       │ 渲染支持平铺、WBS层级、成本穿透、列自定义的动态数据工作台

       │ 两票制闭式解析公式求解综合单价 CJ，分离 13% 制造票与 9% 安装票

[甲方清单适配与 9 费项倒轧]
       │ 聚合至 010101 实腹钢柱等清单项，倒轧制作费并验证安全阈值
       ▼
[产出首轮执行报告 003_walkthrough]
```
