## 2. 核心架构与技术实现细节

### 2.1 基础数据库新增截面族规则体系 (`data.json`)
在 `src/gui/workbench/data.json` 中注入完整的 `section_families` 实体列表，支持多规则前缀判定与微工序定额绑定：

```json
{
  "section_families": [
    {
      "family_code": "CROSS",
      "family_name": "十字形钢柱",
      "prefix_rules": ["十", "十字", "CROSS"],
      "default_material": "Q355B",
      "thick_rule": "取最后两位或肢板厚度",
      "bound_fab_norm": "胎架组立(95) + 埋弧焊(120) + ≥80mm厚板调价(140)",
      "bound_inst_norm": "高空吊装就位(618.05) + 机械措施(769.33)",
      "is_builtin": true
    },
    ...
  ]
}
```

### 2.2 截面规格智能推导算法（前端动态解析）
前端 `parseSectionSpecIntelligent(spec)` 引擎遵循 `TakeoffAnalyzer` 规则并结合后台截面族规则：
1. 优先扫描用户在基础数据中配置的 `prefix_rules`；
2. 提取规格中的尺寸数字（如 `十1300x600x80x80` 提取 `[1300, 600, 80, 80]`）；
3. 十字柱与箱型截面智能提取厚度并求最大值作为主板厚度；
4. 联动基础定额微工序判断是否触发 `≥80mm` 厚板焊接调价等定额规则。

### 2.3 两票制闭式解析单价即时求解公式
$$\text{综合单价 } C_J = \frac{(C_{\text{fab}} + C_{\text{trans}}) \times 1.13 + C_{\text{inst}} \times 1.09}{1.0 - (r_{\text{mgmt}} + r_{\text{profit}}) \times 1.09}$$
在编辑模式下，修改任意费用项，直接执行该代数解析式并渲染为醒目绿色预览，点击保存即可精准更新该构件的单价与合价。

## 4. 交互操作指南

1. **访问系统**：浏览器打开 [http://localhost:8765/app.html](http://localhost:8765/app.html)；
2. **体验基础数据·截面族后台设置**：
   - 点击左侧菜单 **`③ 基础数据`**；
   - 查看首个标签页 **`1. 截面族规则设置 (Section Families)`**；
   - 可在右侧“推导规则在线仿真沙盒”中输入任意规格进行推导测试；
   - 点击“+ 新增截面族”可自定义新截面分类。
3. **体验算量工作台 Auto-Pull 动态拉取与在线调价**：
   - 点击左侧菜单 **`④ 算量工作台`**；
   - 在构件平铺表点击任意行（例如 `ROW-16 钢柱十字型` 或 `ROW-19 钢柱焊接箱型`）；
   - 查看右侧面板：数据均动态拉取自基础定额；
   - 点击右上角 **`✏️ 编辑调价`** 按钮切换至编辑模式；
   - 可自由调整规格、材质、板厚、材料价、制作费、安装费、运距；
   - 观察底部的**两票制解析单价**实时重新计算；
   - 点击 **`💾 应用并更新当前构件`** 即可同步保存并更新当前构件与全案金额，或点击 **`🔄 恢复定额默认值`** 一键复原。
