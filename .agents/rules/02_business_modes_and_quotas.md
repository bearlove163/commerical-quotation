# 规则集 02: 业务模式硬隔离、双轨制安装与定额微工序规范 (Business Modes & Quota Norms)

> **生效级别**：强制执行 (Mandatory)  
> **适用范围**：项目立项、模式路由、算量工作台、工序定额库

---

## 核心规则条目

### Rule 6: 业务模式硬隔离原则 (Domestic vs Overseas Hard Separation)
- **国内工程与国际贸易物理隔离**：
  * **国内工程 (两票制)**：制作 13% 专票 + 安装 9% 建安劳务专票；
  * **境外工程 (Incoterms 2020)**：EXW (工厂交货), FOB (离岸交货), CFR (到港交货), DAP (目的地未完税交货), DDP (完税交货), DDP+现场安装 (EPC全包)；
- 项目根实体必须强制互斥选择 `business_mode`，底层组价计算管道必须依据此枚举进行物理路由，**严禁混用算法或混开税票**。

### Rule 7: 安装计价双轨制原则 (Quotas vs Day-Rate Dual Track)
- **国内现场安装**：套用成熟的企业工序定额（元/t），按分项基价、辅料与机械分摊测算；
- **境外新兴市场安装**：**严禁套用国内定额**！强制采用：
  1. **人员派驻吃住行综合人天成本法 ($C_{\text{manday\_labor}}$)**：基本工资 + 外派艰苦津贴 + 伙食标准 + 住宿标准 + 属地交通 + PPE劳保包日摊销 + 国际救援险日摊销；
  2. **国际差旅与签证**：往返航班机票 + 属地工作许可与签证；
  3. **海外现场开办费包 ($C_{\text{preliminaries}}$)**：营地临建租金、发电机与动力、临时堆场、属地合规安保包。

### Rule 10: 算量工作台核心地位与定额自动拉取原则 (Takeoff Core & Auto-Pull) ⭐
- **算量工作台 (MODULE 4) 是系统最核心、最高频的业务入口**；
- 支持键盘高效手工录入构件编号、名称、截面规格（如 `十1300x600x80x80`、`箱1600x1800x55x55`、`P1600x30`）、材质与工程量；
- 录入后，截面解析器智能推导几何大类（CROSS, BOX, PIPE, SPHERE, TRUSS, H_BEAM）与最大板厚，**系统秒级自动向底层定额库拉取（Auto-Pull）车间制作定额、安装定额与材料快照价**，免去人工查找。

### Rule 11: 定额微工序高精细度解耦与可扩展性原则 (Granular Decoupled Norms) ⭐
- 坚决摒弃原始 Excel 仅有单一加工费基价的粗糙做法；
- 定额库强制执行**微工序高精细度解耦**：
  * **车间制作 7 道微工序**：1. 数控下料切割、2. 组对拼装点焊、3. 埋弧自动焊主焊缝、4. 探伤矫正与回火、5. 空间立体预拼装、6. 表面抛丸除锈 Sa2.5、7. 工厂底中漆喷涂；
  * **现场安装 6 道微工序**：1. 现场卸货倒运、2. 地面拼装胎架、3. 高空吊装就位、4. 高强螺栓初终拧、5. 现场高空对接焊接、6. 焊缝补漆与安全措施；
- **单项工序调优驱动全案热重算**：当某工序引入创新工法（如机器人自动焊接、激光切割替代）或工价变动时，仅需微调单项微工序指标，全案秒级出数。

### Rule 20: 深度正交材料规则引擎与长期横向比较原则 (Orthogonal Material Pricing & Horizontal Benchmark Engine) ⭐
- **摒弃扁平化文本定价**：严禁将“材质+板厚”作为单一硬编码文本维护，必须采用**六大正交原子维度解耦**：
  1. **钢种族 (Family)**：碳素钢、低合金高强钢、高建钢(GJ)、超高强钢(UHSS: Q690/Q890/Q960)、耐候钢、不锈钢、耐磨板；
  2. **屈服强度等级 ($\sigma_y$)**：235、345、355 (基准 0)、390、420、460、550、690、890、960 MPa；
  3. **冲击韧性温度等级**：A级 (常温)、B级 (+20℃基准)、C级 (0℃)、D级 (-20℃)、E级 (-40℃)、F级 (-60℃极寒)；
  4. **冶金与交货工艺状态 (Delivery State)**：热轧 AR、控轧 CR、**TMCP (控轧控冷免预热 · 核心工艺)**、正火 N、正火加回火 N+T、调质 QT (Q690/Q960核心工艺)；
  5. **连续板厚阶梯区间 ($\delta$)**：薄板 ($\le 6\text{mm}$)、中板基准 ($8 \sim 14\text{mm}$)、厚板 ($16 \sim 40\text{mm}$)、特厚板 ($42 \sim 80\text{mm}$)、超厚重特板 ($82 \sim 120\text{mm}$)；
  6. **质量技术性能加价**：Z向性能 (Z15/Z25/Z35)、超声波探伤 (GB/T 2970 一级/二级)、真空脱气 (RH/VD)；
- **TMCP 全生命周期综合成本决策**：
  * TMCP 钢板虽材料出厂价略高（约 $+180\text{ 元/t}$），但超低碳当量特性使其构件焊接时免预热或大幅降低预热温度，在车间制作与现场安装微工序中显著降低电费、人工与探伤返修成本，系统必须支持全生命周期方案经济性比选；
- **长期横向比较机制与逆向剥离算法**：
  * 系统必须提供**等效基准逆向剥离算法**，将任意复杂规格（如 `Q690D-TMCP-Z25-40mm`）剥离强度、TMCP、板厚、Z向及调运运杂费后，还原为标准普板出厂基价（$P_{\text{eq\_355B\_10mm}}$），支撑跨项目、跨钢厂、跨周期的横向趋势对账。

### Rule 21: 构件加工厂至主供钢厂调运运杂费动态关联原则 (Mill-to-Fab Logistics Transfer Engine) ⭐
- **到厂综合结算价闭式求解公式**：
  $$P_{\text{landed}} = (P_{\text{base}} + \Delta P_{\text{grade}} + \Delta P_{\text{temp}} + \Delta P_{\text{process}} + \Delta P_{\text{thick}} + \Delta P_{\text{perf}}) \times (1 + \alpha_{\text{loss}}) + T_{\text{freight}} + C_{\text{handling}}$$
- **调运运费矩阵治理**：
  * 系统集中维护制造加工厂基地（江门、中山、武汉、长兴等）至各大主供钢厂（宝武湛江、韶钢、湘钢、沙钢、武钢、舞钢等）的运距、运输模式（公路平板汽运、沿海散货水运、长江内河驳船、铁水联运）与吨运费 $T_{\text{freight}}$；
  * 算量模型必须强制关联承接加工厂基地，自动匹配调运运费，终结传统“拍脑袋粗估运费”模式。

### Rule 22: 专业分包产品字典与合格供应商名录库治理原则 (Subcontract Dictionary & Vendor Registry) ⭐
- **六大专业分包产品字典标准入库**：
  * 完整收录拉索结构体系、空间交汇铸钢节点、组合楼承板系统（闭口型/开口型/钢筋桁架板）、防腐与防火涂装体系、抗震减隔震球型支座、专项无损检测包等标准参数与单价区间；
- **合格分包商与供应商结构化名录**：
  * 集中沉淀企业资质等级、供应范围、注册资金、服务区域、合作履约评级（AAA/AA/A）与指导下浮折扣；
- **轻量预留外部数据拉取 Adapter 接口**：
  * 预留 `IExternalDataPuller` 适配器标准规范与文件导入插槽，保持架构轻量与即插即用。

### Rule 23: 独立 Dialog 弹窗管理与微工序调优解耦原则 (Decoupled Dialog Management Architecture) ⭐
- 面向工作台及后续各业务模块，必须提供标准化、无耦合的独立 Dialog 管理接口：
  1. `openQuotaManagementDialog(type, quotaId)`：7道制作或6道安装微工序穿透试算与调优；
  2. `openMaterialMatrixDialog()`：正交材料选型、板厚加价与钢厂调运费闭式测算；
  3. `openSubcontractDialog(category)`：专业分包产品快速选型与综合询价对比；
  4. `openMachineryDialog()`：大型起重机械方案调配与区域进退场运费试算；
- 各 Dialog 必须支持独立唤起、实时计算、一键回填与另存快照，禁止跨模块紧耦合硬编码。
